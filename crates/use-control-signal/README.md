# use-control-signal

Control signal validation and saturation helpers.

## Install

```toml
[dependencies]
use-control-signal = "0.0.1"
```

## Scope

Use `use-control-signal` when you need explicit clamping, saturation, scaling,
and validation helpers for actuator or controller outputs.

## RustUse workspace

This crate is part of the `use-control` workspace. Depend on `use-control` when
you want the full facade.

## Status

This crate is experimental and may evolve while the workspace remains below
`0.3.0`.
